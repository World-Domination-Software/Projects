# Welcome

Welcome to the documentation site for World Domination Software applications.

This site is for both users and developers and brings together:

- Application pages covering overviews, features, architecture, and support for each WDS app.
- Getting started guides for installing or launching our applications.
- Help for troubleshooting common problems, including performance and multiplayer.
- Guidance on how to report bugs and request features.
- A high-level roadmap for where we would like to take our projects.

## Start here

If you are new, begin with:

- [Applications](applications.md) – index of all WDS applications with links to their documentation.
- [Getting Started](getting-started.md) – overview of this hub and how to get started.

Then explore:

- [Multiplayer](multiplayer.md) – online connection tips, NAT/VPN/firewall checklist.
- [Troubleshooting](troubleshooting.md) – quick fixes and performance tips.
- [Bug Reporting](bug-reporting.md) – how to write clear, actionable bug reports.
- [FAQ](faq.md) – answers to common questions about our applications.
- [Roadmap](roadmap.md) – current areas of focus (subject to change).

For community discussions, ideas, and support, please use our GitHub Discussions:

- https://github.com/World-Domination-Software/Projects/discussions
