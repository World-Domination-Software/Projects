# START HERE – Welcome to Discussions

Welcome to the **World Domination Software LLC** public hub. This post is intended to be pinned at the top of Discussions as a starting point for new visitors.

## What this space is for

Use Discussions when you:

- Need help troubleshooting but are not yet sure it is a bug.
- Have questions about features, platforms, or settings.
- Want to share general feedback, suggestions, or ideas.
- Would like to talk about the roadmap at a high level.

If you already have a clear, reproducible problem, you may want to go directly to **Issues** instead (see below).

## Where should I post?

- **Support / Q&A categories** – Questions about how something works or how to fix a problem.
- **Ideas / feedback categories** – High-level suggestions and quality-of-life improvements.
- **Roadmap category** – Follow and discuss high-level plans and themes.

Before posting:

- Search existing discussions by keyword to see if your topic already exists.
- Read any pinned threads for category-specific rules or context.

## When to use Issues instead

Open an **Issue** (using the appropriate template) when you have a clear, focused problem such as:

- A repeatable gameplay or UI bug.
- A crash, hard freeze, or save corruption.
- A multiplayer connectivity problem.
- Significant performance problems that remain after basic tuning.

If you are not sure which path is best, start with a Discussion. Maintainers can convert it to an Issue if needed.
