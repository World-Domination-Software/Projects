# Press kit

This page collects basic information and assets for people who want to cover or showcase our projects.

## About World Domination Software LLC

World Domination Software LLC (WDS) is a small studio focused on building thoughtful, systems-driven games and the tools that support them. Our work includes:

- Cooperative and survival-focused game experiences.
- Backend services and tools for hosting and managing game servers.
- Experiments with automation, simulation, and community-driven content.
