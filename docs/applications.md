Each application page covers:

- **Overview** – what the application is and who it is for.
- **Purpose** – the problem it solves or the experience it delivers.
- **Features** – a summary of key capabilities.
- **Architecture** – high-level technical structure and platform notes.
- **Development Status** – current release state and near-term focus.
- **Support** – where to get help, file bugs, and join discussions.
