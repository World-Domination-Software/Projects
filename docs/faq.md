# FAQ

Frequently asked questions about our projects and this repository.

## Where do I report bugs?

Use the **Bug report** or **Crash report** issue templates in this repository. For general support questions, start in Discussions.

## Which platforms are supported?

We aim to support PC (Windows, Linux, Steam Deck) and mobile platforms (Android, iOS) where possible. Exact support may vary by project or release.

## How do I share feedback or ideas?

Use GitHub Discussions for ideas, feedback, and suggestions. For well-defined feature requests, use the **Feature request** issue template.

## Can I contribute code or content?

Yes, in some cases. Please read [CONTRIBUTING.md](../CONTRIBUTING.md) before starting work, and open an issue or discussion for larger proposals.

## How do I check if a bug is already known?

- Search existing issues with relevant keywords.
- Look for issues labeled `known-issue` or `confirmed`.

## What if my question doesn’t fit any template?

If it is a general question, use Discussions. If it is very specific and actionable, you can use the **Question** issue template.
