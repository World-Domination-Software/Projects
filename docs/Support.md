# Support

This page explains how to get help and where to direct different types of questions.

---

## When to use Discussions

Use [GitHub Discussions](https://github.com/World-Domination-Software/Projects/discussions) when you:

- Need help but are not certain the problem is a bug.
- Have a question about a feature, platform, or setting.
- Want to share feedback or ideas.
- Want to discuss the roadmap or future directions.

Good practices for Discussions:

- Browse existing topics before opening a new one — your question may already be answered.
- Use a clear, descriptive title so others can find similar questions later.
- Include relevant context such as your platform, game version, and what you already tried.

---

## When to use Issues

Use [GitHub Issues](https://github.com/World-Domination-Software/Projects/issues) when you have a clear, reproducible problem:

- A repeatable gameplay or UI bug.
- A crash, freeze, or data loss.
- A multiplayer connectivity problem that affects gameplay.
- A significant performance problem that persists after basic troubleshooting.

If you are unsure whether to use an Issue or a Discussion, start with a Discussion. A maintainer can convert it to an Issue if appropriate.

See [[Bug-Reporting]] for guidance on what to include in a bug report.

---

## How to ask a good support question

1. **Describe what you were doing** when the problem occurred.
2. **Describe what you expected** to happen.
3. **Describe what actually happened.**
4. **Include your platform and version** — operating system, device type, and game or app build number.
5. **List steps to reproduce** if the problem is consistent.
6. **Include relevant logs or screenshots** if available (avoid sharing personal data).

The more detail you provide upfront, the faster we can help.
