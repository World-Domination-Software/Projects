# Multiplayer & online play

This page covers common multiplayer and online connectivity topics for our projects.

## Basic checklist

If you are having trouble joining or hosting games:

- Make sure all players are running a similar **game version / build**.
- Check that your **internet connection** is stable (avoid heavy downloads or streaming in the background).
- If possible, prefer **Ethernet** over Wi-Fi for hosting.
- Disable or configure VPNs, firewalls, and antivirus tools that might block traffic.

## NAT, routers, and firewalls

Multiplayer connections can be affected by router and network settings:

- Strict or symmetric NAT types may prevent players from joining each other directly.
- Some routers block peer-to-peer traffic by default.
- Corporate, school, or public networks may limit the needed ports entirely.

If you suspect NAT or router issues:

- Try connecting from a different network (for example, a mobile hotspot) as a quick test.
- Reboot your router and modem.
- Check your router's documentation for port forwarding or UPnP settings if you are comfortable doing so.

## VPNs and proxies

- VPNs can change your route and latency, and may block or reroute game traffic.
- If you have connection issues, try temporarily disabling VPNs or proxies to see if it helps.

## When to file a multiplayer issue

If you still cannot play together after trying these steps:

- File a **Multiplayer / online issue** and include:
  - Platform(s) for each player.
  - Whether you are on Wi-Fi, Ethernet, or mobile.
  - Any VPNs or special network setups.
  - Clear steps to reproduce the problem.

This information helps us distinguish between game bugs and network configuration issues.
