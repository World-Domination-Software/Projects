# Troubleshooting Index

This page is a symptom-based index to help you quickly find solutions to common problems. Start with the symptom that matches your situation.

---

## Game will not launch

- Verify your operating system and graphics drivers are up to date.
- Confirm the game files are not corrupt — use your platform's file verification tool (e.g., Steam "Verify Integrity of Game Files").
- Temporarily disable overlays and third-party tools (Discord, GeForce Experience, etc.) and try again.
- Check the launcher or console output for error messages and include them in a bug report if the problem persists.

→ See [[Bug-Reporting]] if the issue repeats after these steps.

---

## Low FPS or stuttering

- Lower graphics settings such as resolution, shadow quality, or anti-aliasing.
- Close background applications that use CPU, GPU, or disk heavily.
- Run the game from an SSD if possible.
- On laptops, ensure you are plugged in and not in battery saver mode.
- Update your graphics drivers.

→ See [[Bug-Reporting]] for performance issue reports.

---

## Multiplayer disconnects

- Check your internet connection and router.
- Disable VPN or proxy software temporarily.
- Make sure the game ports are not blocked by a firewall.
- Verify the game servers are operational — check [Discussions](https://github.com/World-Domination-Software/Projects/discussions) for any status announcements.
- Restart both the game and your router.

→ See [[Bug-Reporting]] for connection problem reports.

---

## Cannot connect to server

- Confirm the server is running and accepting connections.
- Check that your firewall or router is not blocking the required ports.
- For the Game Servers Panel, see the [[Game-Servers-Panel]] wiki page and its linked documentation.

→ See [[Support]] if you need further help.

---

## Missing files or failed downloads

- Re-run the installer or use your platform's file verification or repair tool.
- Temporarily disable antivirus software that might quarantine game files and add the game folder to your exclusion list.
- Ensure you have sufficient disk space.

→ See [[Bug-Reporting]] if files continue to be removed or corrupted.

---

## Controls not working

- Check your input settings in-game and reset them to defaults.
- For controller issues, verify the controller is recognized by your operating system before launching the game.
- Disconnect and reconnect the controller.
- If using keyboard and mouse, check for conflicting keybinds.

→ See [[Support]] for further assistance.

---

## UI not loading or rendering incorrectly

- Make sure your graphics drivers are up to date.
- Try setting the game to windowed mode or a lower resolution.
- Delete any cached settings or config files if the game provides an option to do so.

→ See [[Bug-Reporting]] if the issue persists.

---

## Still stuck?

If none of the steps above resolve your issue:

1. Check [[Support]] for how to get help.
2. Search [Discussions](https://github.com/World-Domination-Software/Projects/discussions) for similar reports.
3. File an issue using [[Bug-Reporting]] guidelines.
