# Troubleshooting

This page lists general steps that can help resolve common problems.

## General checks

Before filing an issue:

- Restart the game and your device.
- Make sure your operating system and graphics drivers are up to date.
- Verify the integrity of game files using your platform's tools (if available).
- Temporarily disable overlays and third-party tools that hook into games.

## Performance issues

- Lower graphics settings such as resolution, shadows, or post-processing.
- Close background applications that may use CPU, GPU, or disk heavily.
- Prefer running on an SSD where possible instead of an HDD.
- On laptops or mobile devices, ensure you are not in a battery saver mode.

## Connection and multiplayer problems

See [multiplayer.md](multiplayer.md) for a dedicated checklist.

## When to report an issue

If you have tried these steps and the problem persists, consider filing an issue using the most relevant template. Include the steps you already tried so we do not ask you to repeat them.
