# Roadkill – Getting Started

← [Back to README](./README.md)

---

## Installation

Roadkill is available on PC (Windows and Linux) and Steam Deck.

1. Purchase or download the game through your chosen storefront (e.g., Steam).
2. Allow the download to complete before launching.
3. Launch the game from your platform client.

On **Steam Deck**, the game is playable with the default Steam Deck configuration. Full controller support is included.

---

## First Launch

On first launch you will be prompted to:

- Choose display and graphics settings (resolution, fullscreen/windowed, quality preset).
- Configure audio preferences.
- Set up control bindings if you want to change the defaults.
- Sign in or create a WDS account for online features, leaderboards, and progression tracking (optional for local play).

---

## Choosing a Mode

From the main menu, select the mode you want:

- **Quick Play** – Join a casual online match quickly.
- **Private Lobby** – Invite friends to a private session.
- **Local Multiplayer** – Split-screen play with controllers.
- **Solo / Practice** – Race or practice offline without other players.

---

## Your First Race

1. Select **Quick Play** or **Solo** from the main menu.
2. Choose a vehicle class (Light for speed, Heavy for combat, or Medium for balance).
3. Select a track or accept a random map assignment in Quick Play.
4. Use the in-game controls to race, attack, and complete the mode objective.

---

## Controls

Default controls are shown in the in-game settings menu and can be fully rebound.

See the [Gameplay](./Gameplay.md) page for a full controls reference.

---

## Tips for New Players

- Start with the Medium vehicle class to get a feel for the handling before committing to a specialization.
- In race modes, use the handbrake for tight corners rather than braking fully.
- In elimination modes, hanging back briefly can let other players eliminate each other early.
- Experiment with different vehicle classes as you unlock them to find your preferred style.
