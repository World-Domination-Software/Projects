# Van Inventory – Troubleshooting

← Back to [[Van-Inventory]]

---

## General Steps First

- Force-close and restart the mobile app or refresh the web dashboard.
- Check that the app is updated to the latest version from your app store.
- Check your internet connection (for sync-related issues).

---

## App Will Not Open or Crashes on Launch

- Update to the latest version of the app.
- Restart your device and try again.
- Uninstall and reinstall if the problem persists (your cloud data is preserved).
- If the issue is reproducible, file a crash report via [[Bug-Reporting]].

## Sync Is Not Working

- Check your internet connection — the app requires connectivity to sync.
- Pull down to manually trigger a sync refresh if available in the app.
- Make sure you are signed in to the correct account on all devices.
- If sync was interrupted (e.g., device ran out of battery mid-sync), reopen the app and allow it to sync completely before making new changes.

## Items Are Not Showing After Scan

- Make sure the barcode or QR code is in your item database. Scanning an unknown code will prompt you to add it.
- Check lighting conditions — poor lighting reduces scan accuracy.
- Try the manual search/entry option if the camera scan is not reading correctly.

## Low-Stock Alerts Not Triggering

- Check that alert thresholds are configured correctly for the affected items (Settings → Items → Edit item → Alert threshold).
- Verify that push notifications are enabled for the Van Inventory app in your device's notification settings.
- Check that email alerts are enabled and your email address is correct in your account settings.

## Reports Not Exporting

- Check that you have sufficient storage space on your device.
- PDF and CSV exports require that the data has fully synced — trigger a sync refresh before exporting.
- If the export button is unresponsive, try refreshing the dashboard or relogging.

## Cannot Access Web Dashboard

- Check that you are using a supported browser (Chrome, Firefox, Safari, Edge — current versions).
- Clear browser cache and cookies for the dashboard domain and try again.
- Make sure you are signed in with the correct account.
