## General

### What is Van Inventory designed for?

Van Inventory is built for field service businesses and mobile operations — technicians, mobile vendors, and small business operators who manage stock across one or more vehicles.

### Is there a web version as well as a mobile app?

Yes. The mobile app (iOS and Android) is designed for field use. The web dashboard is intended for managers and owners to get an overview across all vehicles.

### Does it work offline?

Yes. The mobile app supports offline use — you can log stock changes without an internet connection. Changes sync automatically when connectivity is restored.

---

## Stock and Inventory

### How do I add items to the system?

Items can be added manually through the app or dashboard, or by scanning a barcode or QR code when it is not yet in your database. You will be prompted to create a new item entry on first scan.

### Can multiple operators use the same vehicle?

Yes. Multiple operators can be assigned to a vehicle, and stock changes are attributed to the logged-in operator.

### How do I set up low-stock alerts?

Go to Settings → Items → Edit item, and set an alert threshold. When stock falls below this level, you will receive a push notification and/or email (depending on your notification settings).

### Can I manage more than one van?

Yes. Multi-vehicle support is included — you can create and manage multiple vehicle profiles from a single account.

## Data and Export

### What export formats are available?

CSV and PDF. Exports are generated from the web dashboard and from the mobile app.

### Is my data backed up?

Yes. All data is stored and synced to the WDS cloud service. Your data is available on any device you sign in to.

### Can I import existing inventory from a spreadsheet?

CSV import is a planned feature. Check [[Roadmap]] for current status.
