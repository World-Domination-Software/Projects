# Roadkill – Troubleshooting

← Back to [[Roadkill]]

---

## General Steps First

- Restart the game and your device.
- Verify game files through your platform (Steam: Right-click → Properties → Installed Files → Verify integrity).
- Make sure your OS and GPU drivers are up to date.
- Disable overlays (Steam Overlay, Discord, GeForce Experience).

---

## Game Will Not Launch

- Verify game file integrity (see above).
- Check that antivirus or firewall software is not blocking the game executable.
- Run as administrator on Windows if you get a permissions error.

## Low FPS or Physics Stuttering

- Lower graphics and physics quality settings in the in-game options.
- Close background applications using CPU or GPU heavily.
- On laptops: disable battery saver mode and verify the game is using the dedicated GPU.
- Prefer running the game from an SSD over an HDD for faster asset loading.

## Game Crashes or Freezes

- Update your GPU drivers.
- Verify game file integrity.
- Check the game log for error messages and include them in a crash report.
- If you are using overclocking profiles, revert to stock settings and test.

## Multiplayer – Cannot Find or Join a Match

- Make sure all players are on the same game version.
- Check your internet connection and prefer Ethernet over Wi-Fi.
- Disable VPNs and proxies during play.
- Check that your firewall allows the game's network traffic.

## Multiplayer – Disconnects During Match

- An unstable connection is the most common cause. Avoid running downloads or streams during play.
- Reboot your router and modem, then retry.
- If you are on Wi-Fi, move closer to your router or switch to Ethernet.

## Controller Not Detected

- Connect your controller before launching the game.
- On PC, check that the controller is recognized by the OS (check in Device Manager on Windows or `jstest` on Linux).
- Try a different USB port or cable.
- Wireless controllers: check battery level and re-pair if needed.

## Local Multiplayer Issues

- Ensure all controllers are connected and recognized before starting a local session.
- Split-screen performance may vary depending on your hardware — try lowering graphics settings if it is choppy.
