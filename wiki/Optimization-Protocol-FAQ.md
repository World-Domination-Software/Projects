## General

### What does Optimization Protocol actually do?

It analyzes your system's hardware and software configuration, identifies performance bottlenecks, and provides ranked recommendations for improvement. You can apply changes through the application and measure the before/after difference.

### Does it require an internet connection?

No — core analysis and recommendations run fully locally. Internet connectivity is only needed for optional features like cloud profile sync.

### Does it modify system settings automatically?

Only with your explicit confirmation. The application presents each recommendation and requires you to approve before any change is applied. You can review and undo most changes through the application.

### What platforms are supported?

Windows and Linux desktop. See the product page for specific version requirements.

---

## Profiles and Data

### What is a profile?

A profile is a saved set of optimization settings for a specific use case (e.g., gaming, office work, content creation). You can create multiple profiles and switch between them as needed.

### Are my profiles backed up?

Profiles are stored locally by default. Cloud backup is a planned feature — check [[Roadmap]] for current status.

### Will applying recommendations affect my existing software?

Recommendations are targeted at performance settings and do not modify installed applications. A small number of changes may affect system behavior; the application describes each change before you apply it.

## Technical

### How do I report a bug?

See [[Bug-Reporting]] for how to choose the right template and what to include.

### Where are the application logs?

On Windows, logs are typically in `%APPDATA%\OptimizationProtocol\Logs\`. On Linux, check `~/.config/OptimizationProtocol/`. If you cannot locate them, ask in [Optimization Protocol Support Discussions](https://github.com/World-Domination-Software/Projects/discussions/categories/optimization-protocol-support).
