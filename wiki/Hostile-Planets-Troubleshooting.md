# Hostile Planets – Troubleshooting

← Back to [[Hostile-Planets]]

---

## General Steps First

Before trying specific fixes, run through these:

- Restart the game and your device.
- Verify game files through your platform (Steam: Right-click → Properties → Installed Files → Verify integrity).
- Make sure your OS and GPU drivers are up to date.
- Temporarily disable overlays (Steam Overlay, Discord, GeForce Experience).

---

## Game Will Not Launch

- Check that your system meets the minimum requirements listed on the store page.
- Verify game file integrity (see above).
- Run as administrator on Windows if you get a permissions error.
- Check that antivirus or firewall software is not blocking the game executable.

## Low FPS or Stuttering

- Lower graphics settings (resolution, shadows, anti-aliasing, post-processing).
- Close background applications using CPU, GPU, or disk heavily.
- Ensure you are running from an SSD rather than an HDD.
- On laptops: disable battery saver mode and verify the game is using the dedicated GPU (not integrated graphics).

## Game Crashes or Freezes

- Update your GPU drivers to the latest version.
- Verify game file integrity.
- Check the game log for error messages and include them in your bug report.
- If you are using overclocking or custom GPU profiles, try reverting to stock settings.

## Leaderboards Not Updating

- Make sure you are signed in to your WDS account.
- Check your internet connection.
- Scores are submitted after a level is completed — scores from incomplete runs are not uploaded.

## Save Data Issues

- Cloud saves require a WDS account and an active internet connection during the save event.
- If save data appears missing, check that you are signed in to the correct account.
- Do not exit the game while it is saving (wait for any save indicator to clear).
