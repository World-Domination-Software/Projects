# Applications

This page is the index for all World Domination Software applications documented in this wiki. Each application has a dedicated page covering its overview, purpose, features, architecture, development status, and support information.

## Application pages

- [Game Servers Panel](Game-Servers-Panel) – Infrastructure panel for hosting and managing game servers.
- [Hostile Planets](Hostile-Planets) – Action game set across hostile alien worlds.
- [Optimization Protocol](Optimization-Protocol) – Utility for performance analysis and system optimization.
- [Pure OPS](Pure-OPS) – Fast-paced tactical operations game.
- [Van Inventory](Van-Inventory) – Business tool for managing van-based mobile inventory.
- [Roadkill](Roadkill) – Vehicular action game.

## Page structure

Every application page follows the same structure so documentation is easy to navigate:

| Section | Content |
|---|---|
| Overview | Short description of the application and its target audience |
| Purpose | The problem it solves or the experience it delivers |
| Features | Key capabilities and highlights |
| Architecture | High-level technical design and platform information |
| Development Status | Current release state, known limitations, and near-term focus |
| Support | Where to get help, file bugs, and join community discussions |

## Discussions

Each application also has dedicated GitHub Discussions categories for community interaction:

- **Bug Reports** – Reproducible problems and defects.
- **Feature Requests** – Ideas and improvement proposals.
- **User Support** – Questions, troubleshooting help, and usage guidance.
- **General Discussion** – Everything else related to the application.

For a full guide to discussion categories, see [Community and Discussions](https://github.com/World-Domination-Software/Projects/blob/main/docs/discussions.md).
