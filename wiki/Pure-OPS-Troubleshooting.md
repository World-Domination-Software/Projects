# Pure OPS – Troubleshooting

← Back to [[Pure-OPS]]

---

## General Steps First

- Restart the game and your device.
- Verify game files through your platform (Steam: Right-click → Properties → Installed Files → Verify integrity).
- Make sure your OS and GPU drivers are up to date.
- Temporarily disable overlays (Steam Overlay, Discord, GeForce Experience).

---

## Game Will Not Launch

- Verify game file integrity (see above).
- Check that antivirus or firewall software is not blocking the game executable.
- Run as administrator on Windows if you get a permissions error.

## Low FPS or Stuttering

- Lower graphics settings (resolution, shadows, anti-aliasing, post-processing).
- Close background applications using CPU or GPU heavily.
- Check that the game is running on your dedicated GPU, not integrated graphics.

## Multiplayer – Cannot Connect to Match

- Make sure all players are on the same game version.
- Check your internet connection — prefer Ethernet over Wi-Fi when playing competitively.
- Disable VPNs and proxies during play.
- Check that your firewall allows the game's network traffic.
- If you are behind a strict NAT, connecting to dedicated servers may still work even if peer-to-peer fails.

## Multiplayer – Disconnects During Match

- An unstable internet connection is the most common cause. Check for packet loss or high ping using a tool like `ping` or an online speed test.
- Avoid running large downloads or streams during play.
- Reboot your router and modem, then retry.

## Matchmaking Not Finding Games

- Check that you are connected to the internet and signed in.
- The player pool in ranked modes may be smaller than quick play — try quick play first.
- Ranked matchmaking is currently in development; behavior may vary.

## AI Opponents Behaving Unexpectedly

- Verify game file integrity in case of corruption.
- Check the [known issues list](https://github.com/World-Domination-Software/Projects/issues?q=label%3Aknown-issue) for any reported AI bugs.
- File a bug report via [[Bug-Reporting]] if you have a reproducible case.
