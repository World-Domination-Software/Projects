# Documentation Has Moved

The repo-local `wiki/` folder has been removed as part of a documentation restructuring.

## Where to Find Documentation

- **Application-specific documentation:** See [`docs/applications/`](../docs/applications/) in this repository.
- **Shared documentation (FAQ, support, roadmap, troubleshooting):** See the [GitHub Wiki](https://github.com/World-Domination-Software/Projects/wiki).

## Why

Previously, this folder held markdown pages intended for the GitHub Wiki. This caused confusion between the repo-local `wiki/` folder and the actual GitHub Wiki. All application-specific content has been migrated to `docs/applications/<app-name>/`, and shared content is maintained directly in the actual GitHub Wiki.
