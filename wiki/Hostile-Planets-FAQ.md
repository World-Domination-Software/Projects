## Gameplay

### Is there a story mode or campaign?

Hostile Planets features a series of levels with increasing difficulty rather than a traditional narrative campaign. Lore and world-building are woven into the environments and enemy design.

### Can I play offline?

Yes. Core gameplay is fully playable offline. Leaderboard submission and cloud saves require an internet connection.

### What are the platform requirements?

See the product page on your platform or storefront for minimum and recommended hardware specifications.

### Is there controller support?

Yes. The game supports Xbox-style and PlayStation-style controllers on PC. Steam Deck uses native controller input with pre-configured bindings.

### Does progress carry between runs?

Yes. Upgrades and progression earned during a run can influence subsequent runs, depending on the upgrade type.

## Technical

### How do I report a bug?

See [[Bug-Reporting]] for how to choose the right template and what information to include.

### Where are the game log files?

Log file locations vary by platform. On Windows, logs are typically found in `%APPDATA%\HostilePlanets\Logs\`. On Linux, check `~/.config/HostilePlanets/`. If you need help locating them, post in [Hostile Planets Support Discussions](https://github.com/World-Domination-Software/Projects/discussions/categories/hostile-planets-support).

### The game is crashing. What should I do?

See [[Hostile-Planets-Troubleshooting]] for crash-specific steps. If the issue persists, file a crash report using [[Bug-Reporting]].

## Account and Data

### Do I need a WDS account to play?

No. A WDS account is only required for leaderboards and cloud saves. The core game can be played fully without an account.

### Can I delete my account or data?

For account or data requests, please contact support via [GitHub Discussions – Support](https://github.com/World-Domination-Software/Projects/discussions/categories/hostile-planets-support).
